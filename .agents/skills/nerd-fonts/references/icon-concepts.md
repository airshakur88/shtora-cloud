# Same concept, every set

Data: Nerd Fonts v3.5.1 (`../data/glyphs.tsv`), retrieved 2026-09-01. Names chosen by the maintainer; codes and glyphs come from the snapshot.

Pick one column per surface and stay in it: a statusline in `oct`, an editor UI in `cod`, a file tree in `seti` or `md`. `none` means the set has no direct equivalent. `nf-oct-heart` is U+2665, a standard Unicode character that renders without a Nerd Font.
